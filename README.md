# Preshop — ระบบรับสั่งขนม/อาหารล่วงหน้า

เว็บให้ร้านเปิดรับออเดอร์ล่วงหน้า (ของทำบุญ งานเลี้ยง ของฝาก) ลูกค้าเลือกเมนูแบบกดเพิ่ม-ลด เลือกวันรับ ส่งหรือมารับเอง แล้วโอนพร้อมเพย์หรือจ่ายปลายทาง

## เริ่มใช้งาน

ต้องมี **Node.js 22.13 ขึ้นไป** (แนะนำ 24) — ไม่ต้อง `npm install` เพราะไม่มี dependency เลย

```bash
npm run seed     # (ไม่บังคับ) สร้างร้านตัวอย่าง "ขนมไทยบ้านแม่"
npm start        # เปิดที่ http://localhost:3000
```

บัญชีตัวอย่าง: ผู้ขาย `0800000001`, ผู้ซื้อ `0800000002`
ตอนยังไม่ต่อ SMS จริง รหัส OTP จะแสดงบนหน้าเข้าสู่ระบบ (และใน console)

## ฟีเจอร์

**ลูกค้า**
- เข้าสู่ระบบด้วยเบอร์มือถือ + OTP (บัญชีเดียวใช้ได้ทั้งซื้อและเปิดร้าน) ใส่ Facebook / LINE / IG ฯลฯ ได้
- ค้นหาร้าน/เมนู/พื้นที่ · เลือกเมนูแบบ +/− ใส่หมายเหตุรายเมนู
- เลือกวันเวลารับ (ระบบบังคับวันล่วงหน้า วันหยุดร้าน เวลาทำการ จำนวนที่รับได้ต่อวัน)
- เลือก “ให้ร้านส่ง” (ปักหมุดบนแผนที่ ระบบเช็กระยะจากร้านและพื้นที่ส่ง คำนวณค่าส่ง) หรือ “มารับเอง”
- ระบุโอกาส (ทำบุญ งานเลี้ยง ฯลฯ) ผู้รับ เบอร์ผู้รับ
- ชำระ: โอน (QR พร้อมเพย์พร้อมยอด + แนบสลิป) หรือปลายทาง
- ติดตามสถานะออเดอร์ ยกเลิกเองได้ระหว่างรอร้านยืนยัน
- รีวิวร้าน / บอกร้านว่าอยากให้มีเมนูอะไร / ส่งข้อเสนอแนะถึงทีม Preshop

**ร้าน (หน้า /seller)** — บัญชีเดียวเปิดได้หลายร้าน (สูงสุด 10) สลับร้านได้จากเมนู “ร้านของฉัน” หรือช่องเลือกร้านในหน้าจัดการ
- ประเภทร้าน: ขนมไทย / อาหาร / เบเกอรี่ / เครื่องดื่ม / ชุดทำบุญ / ของใช้ / อื่นๆ (ใช้เป็นตัวกรองหน้าแรก)
- ค่าส่งตามระยะ: ส่งฟรีภายใน X กม. (ค่าเริ่มต้น 3) เกินจากนั้นคิดค่าเริ่มต้น + กม.ละ ... 
- สถานะร้านกดปุ่มเดียว: เปิดรับ / ปิดรับวันนี้ (เปิดเองพรุ่งนี้) / ปิดชั่วคราว
- คิวรับออเดอร์: กด “ตั้งว่าเต็ม” หรือ “หยุด” รายวัน, ตั้งออเดอร์สูงสุดต่อวัน, ตั้งเวลาปิดรับของวัน (สั่งเลยเวลา = นับเป็นวันถัดไป)
- จังหวัด/อำเภอของร้าน เติมให้อัตโนมัติจากหมุด (OpenStreetMap)
- แชทกับลูกค้า (หน้า /chat รวมทุกร้าน)

**ผู้ซื้อ (เพิ่มเติม)** — ปักหมุดที่อยู่ตอนสมัคร/เข้าสู่ระบบ แล้วทุกร้านจะแสดงระยะทางและค่าส่งจริง · ปฏิทินคิวบอกวันว่าง/เต็ม/หยุด · แชทกับร้าน · กรองตามจังหวัด อำเภอ คะแนนดาว ส่งฟรี ส่งถึงบ้านฉัน
- เปิด/ปิดรับออเดอร์ได้ทันที (ปิดแล้วลูกค้ายังดูเมนูได้)
- ภาพรวม: รอยืนยัน, สลิปรอตรวจ, ยอดค้างชำระ, กราฟ 14 วัน, ยอดเดือนนี้, เมนูขายดี
- ออเดอร์: กรองตามสถานะ/การชำระ/วัน ค้นหา เปลี่ยนสถานะ ยืนยันรับเงิน โน้ตภายใน ดาวน์โหลด CSV (เปิดใน Excel ได้)
- ของที่ต้องทำ: รวมจำนวนต่อเมนูของแต่ละวัน (กี่ถ้วย) พร้อมหมายเหตุลูกค้า พิมพ์ได้
- ส่ง/รับของ: รายการที่ต้องส่ง/ลูกค้ามารับในวันนั้น ยอดเงินที่ต้องเก็บ เปิดเส้นทางใน Google Maps
- เมนู: รูป ราคา หน่วย ขั้นต่ำ จำนวนต่อวัน วันล่วงหน้า และ **ระยะส่ง/พื้นที่ส่งแยกรายเมนู** (เช่น บัวลอยไข่หวานส่งแค่สายไหม บางเขน ไม่เกิน 5 กม.)
- ตั้งค่าร้าน: ตำแหน่งร้าน, ระยะส่ง, ค่าส่ง (เริ่มต้น + ต่อกม. + ส่งฟรีเมื่อครบ), พื้นที่ส่ง, เวลาทำการ, วันหยุดประจำสัปดาห์และวันหยุดพิเศษ, พร้อมเพย์/บัญชี
- แจ้งเตือนออเดอร์ใหม่ (เสียง + ตัวเลขบนแท็บ) ทุก 30 วินาที

## Deploy

ขึ้นออนไลน์ด้วย Render หรือ Railway ได้เลย (มีไฟล์ `render.yaml`, `railway.json` ให้แล้ว) ดูขั้นตอนที่ [docs/DEPLOY.md](docs/DEPLOY.md)
ห้ามใช้ Vercel/Netlify แบบตรงๆ เพราะไม่มีดิสก์ถาวร ข้อมูลจะหาย

## แอปมือถือ (PWA)

เว็บนี้ติดตั้งเป็นแอปได้แล้ว: บน Android กด “ติดตั้งแอป” (ปุ่มบนเมนู/ท้ายเว็บ) · บน iPhone ใช้ Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
เปิดจากไอคอนจะเป็นเต็มจอพร้อมแถบเมนูด้านล่าง ไฟล์ที่เกี่ยวข้อง: `public/manifest.webmanifest`, `public/sw.js`, `public/icons/`
(สร้างไอคอนใหม่: `node scripts/make-icons.js`) · ขึ้น Play Store ดู [docs/PLAYSTORE.md](docs/PLAYSTORE.md)

## ตั้งค่าเพิ่มเติม (environment variables)

| ตัวแปร | ความหมาย |
| --- | --- |
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000) |
| `DATA_DIR` | ที่เก็บฐานข้อมูลและรูป (ค่าเริ่มต้น `./data`) |
| `SMS_PROVIDER` | ตั้งเป็น `thaibulksms` เพื่อส่ง SMS จริง (ดู `src/sms.js`) |
| `SMS_API_KEY`, `SMS_API_SECRET`, `SMS_SENDER` | ข้อมูลบัญชีผู้ให้บริการ SMS |
| `ADMIN_PHONES` | เบอร์ผู้ดูแลระบบ คั่นด้วย `,` — ดูข้อเสนอแนะถึงทีมได้ที่ `/feedback` |

## โครงสร้าง

```
server.js          HTTP server + ไฟล์ static
src/api.js         API ทั้งหมด (auth, ร้าน, เมนู, ออเดอร์, รายงาน, feedback)
src/db.js          SQLite (node:sqlite ในตัว Node)
src/sms.js         ส่ง OTP
public/            หน้าเว็บ (HTML + JS ธรรมดา ไม่ต้อง build)
scripts/seed.js    ข้อมูลตัวอย่าง
data/              ฐานข้อมูลและรูปที่อัปโหลด (สำรองโฟลเดอร์นี้โฟลเดอร์เดียวพอ)
```

## ก่อนขึ้นใช้งานจริง

- ต่อ SMS จริง (`SMS_PROVIDER`) — ถ้ายังไม่ต่อ ใครก็เข้าบัญชีเบอร์ไหนก็ได้เพราะรหัสแสดงบนหน้าจอ
- รันหลัง HTTPS (เช่น Caddy / Nginx / Cloudflare) และเพิ่ม `Secure` ให้ cookie ใน `src/api.js`
- ระยะทางคำนวณเป็นเส้นตรงจากร้าน ระยะขับรถจริงจะไกลกว่าเล็กน้อย ตั้งรัศมีเผื่อไว้
